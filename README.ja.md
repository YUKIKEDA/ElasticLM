# ElasticLM

.NET アプリケーション向けのライセンス認証基盤。署名付きライセンスをオフラインで検証し、オンプレミスのサーバーからフローティング（同時利用数）ライセンスを貸し出し、SaaS 型のサービスでライセンスを有効化する。すべての部品が NativeAOT に対応し、単一バイナリで配布できる。

> **状態:** 要件から設計し直している。まだ何も公開しておらず、使える API もない。設計は [`docs/design.ja.md`](docs/design.ja.md)、計画は [`docs/roadmap.md`](docs/roadmap.md) にある。
