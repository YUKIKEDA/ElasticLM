# ElasticLM

A software licensing platform for .NET applications. It verifies signed licenses offline, serves floating (concurrent) licenses from an on-premises server, and activates licenses through a hosted service. Every part is NativeAOT-compatible and ships as a single binary.

> **Status:** being redesigned from its requirements. Nothing is released yet, and there is no API to use. The design is in [`docs/design.ja.md`](docs/design.ja.md) (Japanese) and the plan in [`docs/roadmap.md`](docs/roadmap.md).
