# 行ごとの記録

roadmap の行ごとに、その行の Grill の記録と、退けた案を、`<行の ID>.md`（たとえば `V1d10.md`）に置く。設計の本文（`../design.ja.md`）は、何を作るかを言い、行の記録の要点と、このファイルへのリンクを持つ。

この形は、持ち主の決定（2026-11-13、Issue #407）で始めた。それまでの行の記録は、設計 §20.7 の末尾（「<ID> の Grill」）と `../design-decisions.md` にあり、動かさない。Issue #407 の PR のマージのあとに `main` に入る行から、このフォルダーに置く。

1 つのファイルの形:

```markdown
# <行の ID>（Issue #N）: <行の題>

## Grill の記録

- 測った事実（どの head で、どう測ったか）
- 持ち主が決めたこと（問の番号、決めた案、日付）
- こちらが決めたこと
- テスト、変異の確かめ、測定
- 同じ種類を探した範囲、行の外で見つけたこと（Issue の番号）

## 退けた案

- **決定:** …
- **理由:** …
- **却下した案:** …
```

`../roadmap.md` の行の状態は、表の列だけで表す（済みの一覧は、Issue #407 でやめた）。
